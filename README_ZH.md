# 无尽虚空：绝望迷宫 (The Infinite Void: Labyrinth of Despair)

欢迎来到《无尽虚空：绝望迷宫》。这是一个基于 React 开发的氛围感 Roguelike 迷宫生存游戏。

## 游戏背景
你被困在一个无尽、黑暗、令人幽闭恐惧的迷宫中。除了你自己的呼吸声，迷宫深处似乎还有其他东西在窥视着你。你的目标是尽可能长时间地生存下去。

## 核心机制

### 角色状态
*   **生命值 (Health)**: 你的生存底线。被怪物攻击会减少。
*   **饥饿值 (Hunger)**: 随时间消耗。需要食用 **食物 (FOOD)** 补充。
*   **水分值 (Hydration)**: 消耗速度比饥饿快。需要饮用 **水 (WATER)** 补充。

### 探索与视野
*   迷宫被迷雾覆盖，你只能看清周围的一小片区域。
*   **手电筒 (FLASHLIGHT)**: 开启后可显著扩大视野范围，但会消耗电池。

### 战斗与防御
*   **小刀 (KNIFE)**: 近战武器，有耐久度。
*   **手枪 (GUN)**: 远程武器，需要消耗子弹 (Ammo)。
*   迷宫中存在 **怪物 (MONSTER)**，它们会追踪并攻击你。

### 交互
*   **宝箱 (CHEST)**: 分布在迷宫各处，包含生存所需的物资。
*   **拖放系统**: 你可以通过拖放来装备物品（左手/右手）、使用物品或整理背包。

## 操作指南
*   **移动**: `W` `A` `S` `D` 或 方向键。
*   **冲刺**: 按住 `Shift` 键（增加移动速度但加快饥饿/水分消耗）。
*   **交互**: 靠近宝箱自动打开，或通过 UI 按钮进行操作。
*   **背包管理**: 
    *   将物品拖到左/右装备栏以使用。
    *   将消耗品（食物/水）拖到“食用”区域使用。

## AI 系统
游戏接入了 Google Gemini AI，作为你的“内心独白”。它会根据你遇到的各种事件（发现宝箱、被怪物追击、资源匮乏等）生成压抑且富有氛围的心理描述。

## 本地开发与测试
1.  安装依赖：`npm install`
2.  配置环境变量：在 `.env.local` 中填入你的 `GEMINI_API_KEY`。
3.  启动开发服务器：`npm run dev`
4.  访问地址：`http://localhost:3000`
